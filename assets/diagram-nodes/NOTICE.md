# Diagram assets and layout

The built-in stencils and diagram renderer are original Codex Design vector work. They do not depend on remote icon services.

Automatic layout bundles elkjs 0.12.0, copyright its contributors, distributed under Eclipse Public License 2.0. See ELK-LICENSE.md. The unmodified library source and corresponding release are available at https://github.com/kieler/elkjs/tree/0.12.0 and https://www.npmjs.com/package/elkjs/v/0.12.0. The worker is bundled separately from the editor UI.
